# My Organizer 0.5.2 — восстановление после сбоя 0.5.1

## Важно

Сборка 0.5.2 основана на последнем архиве Claude `organizer-0.5.0(2).zip`, а **не** на нерабочем коде 0.5.1. Исправлены номер версии и механизм автоматической активации сервис-воркера для восстановления. Данные и ключи локального хранилища не изменялись.

## Какие файлы загружать

- `organizer-0.5.2-recovery-changed-only.zip` — только отличающиеся от **сломанной 0.5.1** файлы.
- `organizer-0.5.2-recovery-full.zip` — полная сборка для проверки и резервного хранения.
- **Не использовать** ранее присланный архив Claude с номером 0.5.0 для наложения на сломанную 0.5.1: он подготовлен относительно 0.4.0.

## Установка

1. Ничего не удалять на iPhone: ни иконку установленной PWA, ни сайт/данные Safari.
2. На GitHub в том же репозитории загрузить **содержимое** распакованного архива `changed-only` в корень репозитория. Все файлы — **одним коммитом**, заменяя совпадающие имена. Сохранить ту же ссылку на приложение.
3. Дождаться завершения публикации GitHub Pages.
4. На iPhone при подключённом интернете закрыть приложение из переключателя приложений, открыть его снова. Может понадобиться открыть и перезапустить его ещё раз: старый офлайн-кэш сначала может показывать ошибку, пока новый service worker не установится и не активируется. Подождать несколько минут между попытками.
5. Когда приложение откроется, **сначала проверить старые задачи и списки**, затем сразу открыть ⚙ → «Копии и данные» и сохранить резервную JSON-копию в «Файлы»/iCloud Drive.
6. После этого проверить версию 0.5.2, круглые галочки, перенос выполненных дел вниз, короткое/долгое нажатие, разделы и офлайн-режим.

## Если ошибка осталась

Не стирать данные сайта, не переустанавливать и не импортировать копию поверх имеющихся данных. Сообщить точный текст ошибки и время публикации. Полное восстановление из старой версии на другом origin может не получить доступ к прежнему хранилищу без отдельной инструкции.

## Проверки и ограничения

- Проверен синтаксис и разбор JavaScript-модулей, сопоставление файлов, формирование релиза и неизменность хранилищного формата по коду.
- Тест перехода через сервис-воркер с 0.5.1 на 0.5.2 и браузерные пользовательские сценарии **не были воспроизведены**: среда блокирует обращение Chromium к локальному тестовому серверу.
- Тесты, ранее заявленные Claude для базовой 0.5.0, не равнозначны проверке восстановления из сломанной 0.5.1.
